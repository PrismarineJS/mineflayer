บทช่วยสอนนี้จะช่วยให้คุณเริ่มต้นใช้งาน Mineflayer ได้ แม้ว่าคุณจะไม่รู้อะไรเกี่ยวกับการเขียนโค้ดเลยก็ตาม

## พื้นฐาน

หัวข้อต่อไปนี้เป็นแนวคิดพื้นฐานที่คุณจำเป็นต้องรู้เพื่อเริ่มต้นใช้งาน Mineflayer

### พื้นฐาน Javascript

#### การติดตั้ง Node

ในหัวข้อนี้คุณจะได้เรียนรู้พื้นฐานเกี่ยวกับ Javascript, Node และ NPM

Javascript ซึ่งมักย่อว่า JS เป็นภาษาโปรแกรมที่ออกแบบมาสำหรับเว็บ เป็นสิ่งที่ทำให้การโต้ตอบส่วนใหญ่บนเว็บเกิดขึ้นได้  
Node.js หรือที่มักเรียกสั้น ๆ ว่า Node ทำให้สามารถใช้ Javascript นอกเว็บเบราว์เซอร์ได้

ดังนั้นสิ่งแรกที่คุณต้องทำเพื่อเริ่มต้นคือการติดตั้ง Node คุณสามารถดาวน์โหลดได้[ที่นี่](https://nodejs.org/en/download/)  
หลังจากติดตั้งเสร็จแล้ว ให้เปิด command prompt (หรือที่เรียกว่า terminal) แล้วพิมพ์ `node -v`  
หากคุณติดตั้ง Node ถูกต้อง มันควรจะแสดงหมายเลขเวอร์ชันออกมา หากมันบอกว่าหาคำสั่งไม่เจอ ให้ลองติดตั้งใหม่อีกครั้ง

ตอนนี้คุณมี Node แล้ว คุณสามารถเริ่มเขียนโค้ดได้ แต่เราต้องทำอีก 1 อย่างก่อน  
Javascript สามารถเขียนในโปรแกรมแก้ไขข้อความพื้นฐานใด ๆ ก็ได้ แต่จะง่ายกว่ามากหากคุณใช้สิ่งที่เรียกว่า [Integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment)(IDE)  
IDE จะช่วยคุณเขียนโค้ดเพราะมันสามารถให้คำแนะนำ หรือบอกคุณได้ว่าโค้ดของคุณมีปัญหาที่อาจเกิดขึ้นหรือไม่ IDE ที่ดีสำหรับเริ่มต้นคือ [Visual Studio Code](https://code.visualstudio.com/)(VSCode)  
เมื่อคุณติดตั้งและตั้งค่า VSCode เสร็จแล้ว ให้สร้างไฟล์ใหม่แล้วบันทึกไว้ที่ใดที่หนึ่งโดยใช้ชื่อที่ลงท้ายด้วย `.js` เช่น `bot.js`  
สิ่งนี้จะทำให้ VSCode รู้ว่าเรากำลังทำงานกับ Javascript และให้คำแนะนำที่ถูกต้องแก่คุณ

#### ตัวแปร Javascript

เริ่มต้นด้วยการพิมพ์ดังต่อไปนี้:

```js
const test = 5
```

โค้ดนี้จะสร้างตัวแปรใหม่ชื่อ `test` และกำหนดค่า `5` ให้กับมัน  
ตัวแปรใช้สำหรับเก็บข้อมูลและนำไปใช้ในภายหลังในโค้ด

ตอนนี้ให้บันทึกไฟล์เพื่อที่เราจะได้รันโค้ด เปิด terminal อีกครั้ง (หรือ terminal ใหม่ใน VSCode) แล้วไปยังโฟลเดอร์เดียวกับที่บันทึกไฟล์ไว้ ทำได้โดยใช้คำสั่ง `cd` เช่น `cd Documents\javascript`  
เมื่อ terminal ของคุณอยู่ในโฟลเดอร์เดียวกับไฟล์ Javascript ของคุณแล้ว คุณสามารถรัน `node filename.js`  
หากคุณทำทุกอย่างถูกต้อง คุณควรจะไม่เห็นอะไรเลย  
ในบทถัดไปเราจะแสดงให้คุณเห็นว่าจะ 'พิมพ์' สิ่งต่าง ๆ ออกมาที่ terminal ได้อย่างไร

โดยทั่วไป เป็นแนวทางที่ดีที่จะใช้คีย์เวิร์ด `const` แทนคีย์เวิร์ด `let` เมื่อกำหนดตัวแปร ตัวแปรที่กำหนดด้วย `const` ไม่สามารถแก้ไขได้ในภายหลัง จึงเป็นค่าคงที่ (constant)  
จากนั้น Javascript จะสามารถทำให้โค้ดของคุณทำงานได้มีประสิทธิภาพมากขึ้นเพราะมันรู้ว่าไม่ต้องคำนึงถึงการเปลี่ยนแปลงค่าของตัวแปรนั้น  
แน่นอนว่าหากคุณต้องการตัวแปรที่แก้ไขได้ คุณก็ยังต้องใช้ `let` อยู่ดี

```js
const test = 5
// eslint-disable-next-line
test = 10 // บรรทัดนี้ไม่ถูกต้อง
```

บรรทัดที่สองไม่ถูกต้องเพราะคุณไม่สามารถกำหนดค่าให้ตัวแปร `test` ใหม่ได้

หากคุณต้องการช่วยให้ตัวคุณเองและคนอื่นเข้าใจโค้ดของคุณได้ดีขึ้น คุณสามารถใช้คอมเมนต์ได้  
คอมเมนต์สามารถสร้างได้โดยใช้ `//` และทุกอย่างที่อยู่หลังจากนั้นจะถูก Javascript เพิกเฉยโดยสิ้นเชิง

#### แสดงผลลัพธ์

หลายครั้งที่คุณต้องการดูค่าปัจจุบันของตัวแปร เพื่อให้แน่ใจว่าโปรแกรมของคุณทำงานถูกต้อง  
คุณทำได้โดยการพิมพ์ตัวแปรออกมาที่ terminal  
ใน Javascript เราสามารถทำสิ่งนี้ได้โดยใช้ฟังก์ชัน `console.log()`  

```js
const test = 5

console.log(test)
```

ตอนนี้เมื่อคุณบันทึกและรันโค้ดนี้ คุณควรจะได้เห็นอะไรบางอย่างในที่สุด:

```txt
5
```

#### ฟังก์ชัน Javascript

ต่อไปคุณจะได้เรียนรู้เกี่ยวกับฟังก์ชัน ฟังก์ชันคือชิ้นส่วนของโค้ดที่สามารถนำไปใช้ได้หลายครั้งตลอดโค้ดของคุณ  
สิ่งนี้มีประโยชน์เพราะคุณไม่ต้องพิมพ์อะไรบางอย่างซ้ำหลายครั้ง

```js
const addition = (a, b) => {
  return a + b
}

const test1 = addition(5, 10)
const test2 = addition(1, 0)

console.log(test1)
console.log(test2)
```

`=>` ใช้สำหรับนิยามฟังก์ชัน เรียกว่าตัวดำเนินการลูกศร (arrow operator)  
ก่อนตัวดำเนินการลูกศรคือรายการพารามิเตอร์ ทุกอย่างที่อยู่ระหว่างวงเล็บกลม `()` คือพารามิเตอร์ คั่นด้วยจุลภาค  
พารามิเตอร์คือตัวแปรที่คุณสามารถส่งให้ฟังก์ชันของคุณ เพื่อให้ฟังก์ชันของคุณทำงานกับมันได้  
จากนั้นหลังตัวดำเนินการลูกศรคือเนื้อหาของฟังก์ชัน ซึ่งก็คือทุกอย่างที่อยู่ระหว่างวงเล็บปีกกา `{}`  
นี่คือที่ที่คุณใส่โค้ดของฟังก์ชัน  
ตอนนี้ฟังก์ชันสมบูรณ์แล้ว เรากำหนดมันให้กับตัวแปรเพื่อตั้งชื่อให้มัน ในกรณีนี้คือ `addition`  

อย่างที่คุณเห็น โค้ดนี้รับพารามิเตอร์ `a` และ `b` แล้วบวกเข้าด้วยกัน  
จากนั้นฟังก์ชันจะคืนค่าผลลัพธ์  
เมื่อนิยามฟังก์ชันแล้ว โค้ดในเนื้อหาของฟังก์ชันจะยังไม่ถูกประมวลผล ในการรันฟังก์ชันคุณต้องเรียกใช้มัน  
คุณสามารถเรียกใช้ฟังก์ชันได้โดยใช้ชื่อของฟังก์ชันตามด้วยวงเล็บกลม ในกรณีนี้คือ `addition()`  
อย่างไรก็ตาม ฟังก์ชัน `addition` ต้องการพารามิเตอร์ 2 ตัว สามารถส่งให้ได้โดยใส่ไว้ในวงเล็บกลม คั่นด้วยจุลภาค: `addition(1, 2)`  
เมื่อฟังก์ชันทำงานเสร็จ คุณสามารถจินตนาการได้ว่าการเรียกฟังก์ชันถูกแทนที่ด้วยสิ่งใดก็ตามที่ฟังก์ชันคืนค่ามา ดังนั้นในกรณีนี้ `let test1 = addition(5, 10)` จะกลายเป็น `let test1 = result` (คุณจะไม่ได้เห็นสิ่งนี้จริง ๆ แต่มันช่วยให้คุณเข้าใจแนวคิดได้)

บางครั้งคุณจะพบสิ่งต่อไปนี้: `function addition() {}` ซึ่งหมายความเหมือนกัน แม้ว่า `() => {}` จะเป็นที่นิยมมากกว่า (หากคุณอยากรู้จริง ๆ ว่าทำไม ให้ค้นหา 'javascript function vs arrow function')

โค้ดข้างต้นควรจะแสดงผลลัพธ์ดังต่อไปนี้:

```txt
15
1
```

#### ชนิดข้อมูลใน Javascript

จนถึงตอนนี้เราทำงานกับตัวเลขเท่านั้น แต่ Javascript สามารถทำงานกับชนิดของตัวแปรได้มากกว่านั้น:

- string คือชิ้นส่วนของข้อความที่สามารถมีตัวอักษรได้หลายตัว string ถูกนิยามโดยใช้เครื่องหมายคำพูด `''`

```js
const string = 'This is a string' // ชนิด string
```

- array คือชนิดที่สามารถเก็บตัวแปรได้หลายตัวภายในตัวเอง array ถูกนิยามโดยใช้วงเล็บเหลี่ยม `[]`

```js
const array = [1, 2, 3] // ชนิด array
```
- object โดยพื้นฐานแล้วคืออาเรย์ขั้นสูง คุณจะได้เรียนรู้เพิ่มเติมเกี่ยวกับมันในภายหลังในบทช่วยสอนนี้ มันถูกนิยามด้วยวงเล็บปีกกา `{}`

```js
const object = {} // ชนิด object
```

- ฟังก์ชันก็เป็นชนิดของตัวมันเองเช่นกัน

```js
const adder = (a, b) => { return a + b } // ชนิด function
```

- boolean คือชนิดที่มีได้เพียง `true` หรือ `false` เท่านั้น

```js
const boolean = true // ชนิด boolean
```

- เมื่อบางอย่างยัง(ไม่)ถูกนิยาม ชนิดของมันคือ `undefined`

```js
let nothing // ชนิด undefined
const notDefined = undefined // ชนิด undefined
```

#### คำสั่ง If

บางครั้งคุณต้องการทำสิ่งต่าง ๆ ที่แตกต่างกันตามเงื่อนไขบางอย่าง  
สิ่งนี้สามารถทำได้โดยใช้คำสั่ง if

```js
const name = 'Bob'

if (name === 'Bob') {
  console.log('Your name is Bob')
} else if (name === 'Alice') {
  console.log('Your name is Alice')
} else {
  console.log('Your name is not Bob or Alice')
}
```

คำสั่ง if ถูกสร้างขึ้นโดยใช้คีย์เวิร์ด `if` หลังจากนั้นคุณมีเงื่อนไขอยู่ระหว่างวงเล็บกลม `()` ตามด้วยเนื้อหาที่อยู่ระหว่างวงเล็บปีกกา `{}`
เงื่อนไขต้องเป็นสิ่งที่คำนวณออกมาเป็น boolean  
ในกรณีนี้ใช้ตัวดำเนินการเท่ากับ `===` ซึ่งจะเป็น `true` หากค่าที่อยู่ข้างหน้าเหมือนกับค่าที่อยู่ข้างหลัง ไม่อย่างนั้นจะเป็น `false`  
หากเงื่อนไขเป็น `true` โค้ดในเนื้อหาจะถูกประมวลผล  
คุณสามารถเชื่อมคำสั่ง if เข้ากับคำสั่ง else-if หรือคำสั่ง else ได้  
คุณสามารถมีคำสั่ง else-if ได้มากเท่าที่ต้องการ แต่มีคำสั่ง if และ else ได้เพียง 1 ตัว  
หากคุณมีคำสั่ง else มันจะถูกเรียกก็ต่อเมื่อคำสั่งที่เชื่อมต่อกันก่อนหน้าทั้งหมดเป็น `false`

#### ลูป

ลูปใช้สำหรับทำซ้ำโค้ดบางส่วนจนกว่าเงื่อนไขบางอย่างจะเป็นจริง

```js
let countDown = 5

while (countDown > 0) {
  console.log(countDown)
  countDown = countDown - 1 // ลด countDown ลง 1
}

console.log('Finished!')
```

โค้ดข้างต้นจะพิมพ์ดังต่อไปนี้

```txt
5
4
3
2
1
Finished!
```

ลูป `while` มีเงื่อนไข `()` และเนื้อหา `{}`  
เมื่อโค้ดมาถึงลูป มันจะตรวจสอบเงื่อนไข หากเงื่อนไขเป็น `true` โค้ดในเนื้อหาจะถูกประมวลผล  
หลังจากถึงจุดสิ้นสุดของเนื้อหา เงื่อนไขจะถูกตรวจสอบอีกครั้ง และหากเป็น `true` เนื้อหาก็จะถูกประมวลผลอีกครั้ง  
สิ่งนี้จะเกิดขึ้นตราบใดที่การตรวจสอบเงื่อนไขยังเป็น `true`  
ในแต่ละลูป โค้ดนี้จะพิมพ์เลข `countDown` ปัจจุบัน แล้วลดมันลง 1  
หลังจากลูปครั้งที่ 5 เงื่อนไข `0 > 0` จะเป็น `false` ดังนั้นโค้ดจะดำเนินต่อไป

ลูป `for` ก็มักถูกใช้บ่อยเช่นกัน และต่างจากลูป `while` เล็กน้อย  

```js
for (let countDown = 5; countDown > 0; countDown = countDown - 1) {
  console.log(countDown)
}
```

แทนที่จะมีแค่เงื่อนไข ลูป for มี 3 ส่วนที่แตกต่างกัน  
ส่วนเหล่านี้คั่นด้วยอัฒภาค (semicolon)  
ส่วนแรก `let countDown = 5` ถูกประมวลผลเพียงครั้งเดียว ที่จุดเริ่มต้นของลูป  
ส่วนที่สอง `countDown > 0` คือเงื่อนไข ซึ่งเหมือนกับลูป while  
ส่วนที่สาม `countDown = countDown - 1` ถูกประมวลผลหลังจากแต่ละลูป:

หากคุณต้องการทำบางอย่างกับทุกรายการในอาเรย์ ลูป `for of` อาจมีประโยชน์  

```js
const array = [1, 2, 3]

for (const item of array) {
  console.log(item)
}
```

ลูป `for of` ต้องมีตัวแปรอยู่ก่อน `of` นี่คือตัวแปรที่สามารถใช้เข้าถึงรายการปัจจุบันได้  
ตัวแปรที่อยู่หลัง `of` ต้องเป็นสิ่งที่บรรจุตัวแปรอื่น ๆ ส่วนใหญ่จะเป็นอาเรย์ แต่ก็มีอ็อบเจกต์บางตัวด้วย  
ลูปจะประมวลผลเนื้อหาสำหรับแต่ละรายการใน `array` และในแต่ละลูปตัวแปร `item` จะเป็นรายการปัจจุบันของ `array`

#### Node Package manager

สิ่งสุดท้ายที่คุณต้องรู้คือวิธีใช้ [Node Package Manager](https://www.npmjs.com/)  
NPM ถูกติดตั้งโดยอัตโนมัติเมื่อคุณติดตั้ง Node  
NPM ใช้สำหรับนำแพ็กเกจที่มีประโยชน์ซึ่งคนอื่นสร้างขึ้นมาใช้ ซึ่งสามารถทำสิ่งที่มีประโยชน์ให้กับคุณได้  
คุณสามารถค้นหาแพ็กเกจได้ที่[เว็บไซต์ของพวกเขา](https://www.npmjs.com/) จากนั้นติดตั้งโดยใช้คำสั่ง `npm install` ใน terminal ของคุณ  
ตัวอย่างเช่น ในการติดตั้ง Mineflayer ให้รัน `npm install mineflayer`  

จากนั้น Node สามารถเข้าถึงโมดูลที่ติดตั้งไว้ได้โดยใช้ฟังก์ชัน `require()`

```js
const mineflayer = require('mineflayer')
```

หลังจากนี้ ตัวแปร `mineflayer` สามารถใช้เพื่อเข้าถึงฟีเจอร์ทั้งหมดของ Mineflayer ได้

### การสร้างบอท

ตอนนี้คุณรู้พื้นฐานของ Javascript, Node และ NPM แล้ว คุณก็พร้อมที่จะเริ่มสร้างบอท (bot) ตัวแรกของคุณ!  
หากคุณไม่รู้คำศัพท์ใด ๆ ข้างต้น คุณควรกลับไปยัง[หัวข้อก่อนหน้า](#พื้นฐาน-javascript)

ด้านล่างนี้คือสิ่งขั้นต่ำที่สุดที่จำเป็นในการสร้างบอท Mineflayer

```js
const mineflayer = require('mineflayer')

const bot = mineflayer.createBot()
```

หากคุณรันตัวอย่างนี้ คุณจะสังเกตเห็นว่าโปรแกรมของคุณจะไม่หยุด หากคุณต้องการหยุดโปรแกรมที่กำลังรันอยู่ ให้กด `Ctrl` + `c`  
อย่างไรก็ตาม บอทนี้ยังไม่ค่อยมีประโยชน์ เพราะโดยค่าเริ่มต้นมันจะเชื่อมต่อกับเซิร์ฟเวอร์ (server) Minecraft ที่รันอยู่บนเครื่องของคุณด้วยพอร์ต 25565  
หากคุณต้องการเลือกว่าจะให้บอทเชื่อมต่อกับเซิร์ฟเวอร์ใด คุณต้องส่งตัวเลือก (options) บางตัวให้กับมัน


```js
const mineflayer = require('mineflayer')

const options = {
  host: 'localhost', // เปลี่ยนเป็น ip ที่คุณต้องการ
  port: 25565 // เปลี่ยนเป็นพอร์ตที่คุณต้องการ
}

const bot = mineflayer.createBot(options)
```

#### อ็อบเจกต์ใน Javascript

วงเล็บปีกกา `{}` ใช้สำหรับสร้างอ็อบเจกต์ (object)  
อ็อบเจกต์มีสิ่งที่เรียกว่าคู่คีย์-ค่า (key-value pair)  
คู่คีย์-ค่าประกอบด้วยทวิภาค `:` โดยมีคีย์อยู่ก่อนทวิภาค และค่าของคีย์นั้นอยู่หลังทวิภาค  
จากนั้นสามารถใช้คีย์เพื่อดึงค่าของมันออกมาได้  
คุณสามารถมีคู่คีย์-ค่าได้หลายคู่โดยคั่นด้วยจุลภาค

```js
const object = {
  number: 10,
  another: 5
}

console.log(object.number) // โค้ดนี้จะพิมพ์ค่า 10
```

แนวคิดนี้มักถูกใช้เพื่อสร้างสิ่งที่เรียกว่า 'named parameters'  
ข้อดีของสิ่งนี้คือคุณไม่จำเป็นต้องใช้ตัวเลือกที่มีให้ทั้งหมด และตำแหน่งของมันก็ไม่สำคัญ  
ค่าสามารถเป็นอะไรก็ได้ แม้กระทั่งอ็อบเจกต์อื่น ๆ หากค่าเป็นฟังก์ชัน ฟังก์ชันนั้นมักถูกเรียกว่าเมธอด (method) ของอ็อบเจกต์นั้น  
คุณยังสามารถสร้างอ็อบเจกต์แบบในบรรทัดเดียวได้ด้วย

```js
const bot = mineflayer.createBot({ host: 'localhost', port: 25565 })
```

#### การล็อกอิน

หากไม่ใส่พารามิเตอร์ใด ๆ บอทจะมีชื่อ `Player` และสามารถล็อกอินเข้าเซิร์ฟเวอร์โหมดออฟไลน์ได้เท่านั้น (Cracked & open-to-lan)  
หากคุณส่งตัวเลือก `username` ให้กับ `createBot` มันจะล็อกอินด้วยชื่อผู้ใช้นั้น (ยังคงเฉพาะในเซิร์ฟเวอร์โหมดออฟไลน์เท่านั้น)  
ในการล็อกอินเข้าบัญชีที่เจาะจง คุณต้องส่งทั้ง `username` และ `password`

```js
const bot = mineflayer.createBot({
  host: 'localhost',
  port: 25565,
  username: 'Player',
  password: 'password'
})
```

#### อาร์กิวเมนต์บรรทัดคำสั่ง

จะเป็นอย่างไรหากมีคนอื่นชอบบอทของคุณและอยากใช้มัน แต่ใช้บนเซิร์ฟเวอร์ที่ต่างออกไปและด้วยบัญชีที่ต่างกัน?  
นี่หมายความว่าทุกคนต้องเปลี่ยนที่อยู่เซิร์ฟเวอร์และการตั้งค่าล็อกอินตามที่ต้องการ (และแน่นอนว่าการแชร์รหัสผ่านของคุณก็เป็นความคิดที่ไม่ดี)  
เพื่อแก้ปัญหานี้ หลายคนใช้อาร์กิวเมนต์บรรทัดคำสั่ง (command line arguments)

```js
const bot = mineflayer.createBot({
  host: process.argv[2],
  port: parseInt(process.argv[3]),
  username: process.argv[4],
  password: process.argv[5]
})
```

อย่างที่คุณเห็น ไม่มีข้อมูลที่ละเอียดอ่อนอยู่ในโค้ดของคุณอีกต่อไป! แต่ตอนนี้ คุณจะรันมันได้อย่างไร?  
ตอนนี้แทนที่จะเริ่มโปรแกรมของคุณด้วยแค่ `node filename.js` คุณจะเริ่มมันด้วย `node filename.js host port username password`  
Node จะแยกบรรทัดคำสั่งทั้งหมดออกมาเป็นอาเรย์โดยอัตโนมัติ คั่นด้วยช่องว่าง  
อาเรย์นี้คือ `process.argv`  
ข้อมูลในอาเรย์สามารถเข้าถึงได้โดยใช้ดัชนี (index) ของแต่ละรายการ ดัชนีเริ่มต้นที่ 0 เสมอ ดังนั้นรายการแรกสามารถเข้าถึงได้ด้วย `[0]` และในกรณีนี้จะเป็น `node` เป็นต้น

| | รายการที่ 1 | รายการที่ 2 | รายการที่ 3 | รายการที่ 4 | รายการที่ 5 | รายการที่ 6 |
| --- | :---: | :---: | :---: | :---: | :---: | :---: |
| ค่า | `node` | `filename.js` | `host` | `port` | `username` | `password` |
| ดัชนี | `[0]` | `[1]` | `[2]` | `[3]` | `[4]` | `[5]`

### การส่งฟังก์ชันเป็นอาร์กิวเมนต์

ไม่ใช่แค่ตัวแปรพื้นฐานอย่างตัวเลขและ string เท่านั้นที่สามารถส่งเป็นอาร์กิวเมนต์ได้  
ฟังก์ชันก็สามารถส่งเป็นตัวแปรได้เช่นกัน

```js
const welcome = () => {
  bot.chat('hi!')
}

bot.once('spawn', welcome)
```

อย่างที่คุณเห็น เมธอด `bot.once()` รับพารามิเตอร์ 2 ตัว  
พารามิเตอร์แรกคือชื่ออีเวนต์ (event) พารามิเตอร์ที่สองคือฟังก์ชันที่จะเรียกเมื่ออีเวนต์นั้นเกิดขึ้น  
จำไว้ว่า เมื่อส่งฟังก์ชัน ให้ใช้แค่ชื่อและไม่ใส่วงเล็บกลม `()`

`bot.chat()` คือเมธอดสำหรับส่งข้อความไปยังแชท (chat)

คุณยังสามารถทำให้โค้ดนี้ง่ายขึ้นได้โดยใช้ฟังก์ชันนิรนาม (anonymous function)  
ฟังก์ชันนิรนามไม่มีชื่อ และถูกสร้างขึ้นที่ตำแหน่งที่ชื่อฟังก์ชันเคยอยู่  
มันยังคงต้องมีรายการพารามิเตอร์ `()` และเนื้อหาของฟังก์ชัน `{}` แม้ว่าจะไม่ได้ใช้ก็ตาม

```js
bot.once('spawn', () => {
  bot.chat('hi!')
})
```

### การฟังอีเวนต์

อ็อบเจกต์ bot มี[อีเวนต์](http://prismarinejs.github.io/mineflayer/#/api?id=events)ที่มีประโยชน์มากมาย
คุณสามารถฟังอีเวนต์ได้โดยใช้เมธอด `bot.on()` หรือเมธอด `bot.once()` ของอ็อบเจกต์ bot ซึ่งรับชื่อของอีเวนต์และฟังก์ชัน
ในการลบ listener ที่เจาะจงออก คุณสามารถใช้เมธอด `bot.removeListener()`

- `bot.on(eventName, listener)`
  ประมวลผลฟังก์ชัน `listener` ทุกครั้งที่อีเวนต์ชื่อ `eventName` ถูกทริกเกอร์
- `bot.once(eventName, listener)`
  ประมวลผลฟังก์ชัน `listener` เพียงครั้งเดียว ในครั้งแรกที่อีเวนต์ชื่อ `eventName` ถูกทริกเกอร์
- `bot.removeListener(eventName, listener)`
  ลบ `listener` ที่ระบุสำหรับอีเวนต์ชื่อ `eventName` ในการใช้สิ่งนี้คุณต้องนิยามฟังก์ชันของคุณด้วย `function myNamedFunc() {}` หรือใส่ฟังก์ชันของคุณไว้ในตัวแปรด้วย `const myNamedFunc = () => {}` จากนั้นคุณสามารถใช้ `myNamedFunc` ในอาร์กิวเมนต์ listener ได้

ไม่ใช่แค่อ็อบเจกต์ bot เท่านั้น อ็อบเจกต์ [`Chest`](http://prismarinejs.github.io/mineflayer/#/api?id=mineflayerchest), [`Furnace`](http://prismarinejs.github.io/mineflayer/#/api?id=mineflayerfurnace), [`Dispenser`](http://prismarinejs.github.io/mineflayer/#/api?id=mineflayerdispenser), [`EnchantmentTable`](http://prismarinejs.github.io/mineflayer/#/api?id=mineflayerenchantmenttable), [`Villager`](http://prismarinejs.github.io/mineflayer/#/api?id=mineflayervillager) ก็มีอีเวนต์ของตัวเองเช่นกัน!

### Promises
[promise](https://nodejs.dev/learn/understanding-javascript-promises) คือฟังก์ชันที่คุณสามารถใช้ตัวแปร `await` เพื่อรอจนกว่างานของมันจะเสร็จสมบูรณ์ (คุณสามารถละ await เพื่อไม่รอผลลัพธ์ได้)

```js
async function consume (bot) {
  try {
    await bot.consume()
    console.log('Finished consuming')
  } catch (err) {
    console.log(error)
  }
}
```

โค้ดข้างต้นจะพยายามบริโภคสิ่งที่บอทกำลังถืออยู่  
เมื่อการบริโภคสิ้นสุดลง ฟังก์ชันที่ส่งไปจะถูกเรียก  
จากนั้นเราก็สามารถทำสิ่งอื่น ๆ ที่เราต้องการทำหลังจากนั้นได้  
ฟังก์ชันนี้ก็อาจถูกเรียกได้เมื่อเกิดข้อผิดพลาดขึ้น

#### วิธีที่ถูกต้องและไม่ถูกต้อง

ด้านล่างนี้คือตัวอย่างของบอทที่จะคราฟต์ (craft) ท่อนไม้โอ๊คให้เป็นไม้กระดานโอ๊คแล้วคราฟต์ต่อให้เป็นไม้

วิธีที่ไม่ถูกต้อง ❌:

```js
function craft (bot) {
  const mcData = require('minecraft-data')(bot.version)
  const plankRecipe = bot.recipesFor(mcData.itemsByName.oak_planks.id ?? mcData.itemsByName.planks.id)[0] // รับสูตรคราฟต์แรกสำหรับไม้กระดานโอ๊ค
  bot.craft(plankRecipe, 1) // ❌ เริ่มคราฟต์ไม้กระดานโอ๊ค

  const stickRecipe = bot.recipesFor(mcData.itemsByName.sticks.id)[0] // รับสูตรคราฟต์แรกสำหรับไม้
  bot.craft(stickRecipe, 1) // ❌ เริ่มคราฟต์ไม้
}
```

วิธีที่ถูกต้องด้วย promises ✔️:

```js
async function craft (bot) {
  const mcData = require('minecraft-data')(bot.version)
  const plankRecipe = bot.recipesFor(mcData.itemsByName.oak_planks.id ?? mcData.itemsByName.planks.id)[0]
  await bot.craft(plankRecipe, 1, null)
  const stickRecipe = bot.recipesFor(mcData.itemsByName.sticks.id)[0]
  await bot.craft(stickRecipe, 1, null)
  bot.chat('Crafting Sticks finished')
}
```

เหตุผลที่วิธีที่ไม่ถูกต้องนั้นผิดก็เพราะว่าเมื่อ `bot.craft()` ถูกเรียก โค้ดจะดำเนินต่อไปด้านล่างในขณะที่บอทกำลังคราฟต์  
เมื่อโค้ดมาถึง `bot.craft()` ตัวที่สอง ตัวแรกอาจยังทำงานไม่เสร็จ ซึ่งหมายความว่าทรัพยากรที่ต้องการยังไม่พร้อมใช้งาน  
การใช้ promises สามารถแก้ปัญหานี้ได้เพราะมันจะถูกเรียกหลังจาก `bot.craft()` เสร็จสิ้นเท่านั้น

อ่านเพิ่มเติมเกี่ยวกับเมธอด [bot.craft()](https://github.com/PrismarineJS/mineflayer/blob/master/docs/api.md#botcraftrecipe-count-craftingtable)

### วนลูปบนอ็อบเจกต์

ลูป `for of` ที่อธิบายไว้ในบท[ลูป](#ลูป)ก็สามารถใช้วนลูปบนอ็อบเจกต์ได้เช่นกัน

หากเรามีอ็อบเจกต์ดังต่อไปนี้:

```js
const obj = {
  a: 1,
  b: 2,
  c: 3
}
```

โค้ดต่อไปนี้จะวนลูปบนค่าทั้งหมดของอ็อบเจกต์

```js
for (const value of Object.values(obj)) {
  console.log(value)
}
```

```txt
1
2
3
```

โค้ดนี้จะวนลูปบนคีย์ทั้งหมดของอ็อบเจกต์

```js
for (const key of Object.keys(obj)) {
  console.log(key)
}
```

```txt
a
b
c
```

คุณยังสามารถวนลูปบนคีย์และค่าพร้อมกันได้ คุณจะต้อง destructure ตัวแปรก่อน ซึ่งอธิบายไว้[ที่นี่](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment)

```js
for (const [key, value] of Object.entries(obj)) {
  console.log(key + ', ' + value)
}
```

```txt
a, 1
b, 2
c, 3
```

ลูปเหล่านี้เป็นไปได้เพราะ `Object.values(obj)` และ `Object.keys(obj)` ทั้งคู่คืนอาเรย์ของค่าและคีย์ของอ็อบเจกต์ตามลำดับ  
`Object.entries(obj)` คืนอาเรย์ที่แต่ละรายการเป็นอาเรย์ที่มี 2 รายการ: คีย์และค่าที่สอดคล้องกับมัน  
สิ่งสำคัญที่ต้องรู้คือ ต่างจากฟังก์ชัน `Object.values()` และ `Object.keys()` ฟังก์ชัน `Object.entries()` ไม่รับประกันว่าลำดับจะเหมือนกับลำดับตอนที่อ็อบเจกต์ถูกนิยาม

ยังมีลูป `for in` อีกด้วย อย่างไรก็ตาม คุณมักจะต้องการใช้ `for of` แทน `for in` เพราะมีความแตกต่างที่สำคัญ  
ลูป `for in` วนลูปบนคีย์ของอ็อบเจกต์แทนที่จะเป็นค่า (เป็นดัชนีในกรณีที่เป็นอาเรย์)
อย่างไรก็ตาม มันไม่ได้วนลูปเฉพาะคีย์ของตัวมันเองเท่านั้น แต่ยังรวมถึงคีย์จากอ็อบเจกต์อื่นที่มัน 'สืบทอด' มาด้วย ซึ่งอาจทำให้สับสนหรือไม่เป็นที่ต้องการ อ่านเพิ่มเติมเกี่ยวกับสิ่งนี้[ที่นี่](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...in)
โดยทั่วไป คุณจะต้องการใช้ `for of` แทน `for in` ดังนั้นโปรดแน่ใจว่าคุณไม่สับสนระหว่างสองตัวนี้

### การสร้างอีเวนต์จากแชท

คุณสามารถสร้างอีเวนต์ของคุณเองจากแชทได้โดยใช้เมธอด [`bot.addChatPattern()`](http://prismarinejs.github.io/mineflayer/#/api?id=botaddchatpatternname-pattern-chatpatternoptions) มีประโยชน์สำหรับเซิร์ฟเวอร์ Bukkit ที่รูปแบบแชทเปลี่ยนแปลงบ่อย
เมธอด [`bot.addChatPattern()`](http://prismarinejs.github.io/mineflayer/#/api?id=botaddchatpatternname-pattern-chatpatternoptions) รับสามอาร์กิวเมนต์ :

- `pattern` - นิพจน์ปกติ (regex) เพื่อจับคู่กับแชท
- `chatType` - อีเวนต์ที่บอท emit ออกมาเมื่อ pattern จับคู่สำเร็จ เช่น "chat" หรือ "whisper"
- `description` - ไม่บังคับ อธิบายว่า pattern นี้มีไว้เพื่ออะไร

คุณสามารถเพิ่ม [Groups and Range](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions/Groups_and_Ranges) เข้าไปใน `pattern` ได้ จากนั้น listener จะกระจายกลุ่มที่จับได้เข้าไปเป็นอาร์กิวเมนต์ของ callback ของคุณตามลำดับ

อ่านเพิ่มเติมเกี่ยวกับ[นิพจน์ปกติ](https://en.wikipedia.org/wiki/Regular_expression)

ตัวอย่าง :

#### ตอบ Hello Bot

ตรงนี้เรากำลังสร้างบอทที่ตอบ 'hello' จากผู้เล่นคนอื่น

```js
bot.addChatPattern(
  'hello',
  /(helo|hello|Hello)/,
  'Someone says hello'
)

const hi = () => {
  bot.chat('Hi!')
}

bot.on('chat:hello', hi)
```

#### แชทแบบกำหนดเอง

การสร้างอีเวนต์โดยอิงจากรูปแบบแชทที่กำหนดเอง  
ตัวอย่างแชทแบบกำหนดเอง:

```txt
[Player] Player1 > Hello
[Admin] Alex > Hi
[Player] Player2 > Help me, im stuck
[Mod] Jim > On my way
```

```js
bot.addChatPattern(
  /^\[(.+)\] (\S+) > (.+)$/,
  'my_chat_event',
  'Custom chat event'
)

const logger = (rank, username, message) => {
  console.log(`${username} said ${message}`)
}

bot.on('my_chat_event', logger)
```

คำอธิบายเกี่ยวกับ regex `^\[(.+)\] (\S+) > (.+)$` สามารถดูได้[ที่นี่](https://regex101.com/r/VDUrDC/2)

## FAQ

### วิธีรันบอทบน android

นี่คือการตั้งค่าอย่างรวดเร็วสำหรับการรันบอทบนอุปกรณ์ android โดยใช้ [Termux](https://termux.com/)

#### ติดตั้ง Termux

ติดตั้ง [Termux](https://termux.com/) แล้วเปิดมันขึ้นมา

#### ตั้งค่า

ติดตั้ง `Node.js`:

```bash
pkg update -y
pkg install nodejs -y
```

❗️ อนุญาตสิทธิ์ Storage ให้กับ Termux ในการตั้งค่าแอป
สร้างโฟลเดอร์ใหม่บนที่เก็บข้อมูลภายใน :

```bash
cd /sdcard
mkdir my_scripts
cd my_scripts
```

ติดตั้ง `mineflayer`:

```bash
npm install mineflayer
```

ตอนนี้คุณสามารถคัดลอก / เก็บสคริปต์ทั้งหมดของคุณไว้ในโฟลเดอร์ `my_scripts` ภายในที่เก็บข้อมูลภายในได้

#### เริ่มรันบอทของคุณ

ในการเริ่มรันบอท ให้รัน Node พร้อมกับชื่อสคริปต์ของคุณ

```bash
node script_name.js
```

❗️ ทุกครั้งที่เปิด Termux คุณต้องเปลี่ยน cwd ไปยัง `/sdcard/my_scripts` ก่อนเริ่มรันบอท:

```bash
cd /sdcard/my_scripts
```
